## 4. How the Implementation Works (Step-by-Step)

### Step 1: The UI & The "Start Session" Button
In [`VoiceAgentView.jsx`](file:///c:/Users/25002/Desktop/V0.1/Vedika/vedika/Vyomanta/frontend/components/voice-tutor/VoiceAgentView.jsx):
- When idle, the user sees a large pill button: **`START SESSION`** with a microphone icon.
- Clicking the button triggers `handleMicToggle()`.
- State transitions: `disconnected` ➔ `connecting` ➔ `connected` / `tutor-speaking`.
- While active, the button turns red into **`END SESSION`**.
- Controls include a **Mute button** (pauses microphone streaming) and a **Clear Log button**.

### Step 2: Microphone Capture & PCM Encoding (16kHz Mono)
Browsers capture audio at arbitrary rates (e.g. 44.1kHz or 48kHz). Gemini Live requires raw **16,000 Hz, 16-bit mono PCM**:

```javascript
// 1. Acquire media stream with hardware AEC & noise suppression
const stream = await navigator.mediaDevices.getUserMedia({
  audio: { echoCancellation: true, noiseSuppression: true }
});

// 2. Force AudioContext to 16,000 Hz
const audioCtx = new (window.AudioContext || window.webkitAudioContext)({ sampleRate: 16000 });

// 3. Buffer audio with ScriptProcessorNode
const source = audioCtx.createMediaStreamSource(stream);
const processor = audioCtx.createScriptProcessor(4096, 1, 1);
source.connect(processor);
processor.connect(audioCtx.destination);

// 4. Convert Float32 [-1.0, 1.0] to 16-bit signed PCM integers Little-Endian
processor.onaudioprocess = (e) => {
  if (ws.readyState !== WebSocket.OPEN || isMuted) return;
  const float32Data = e.inputBuffer.getChannelData(0);
  const pcmBuffer = new ArrayBuffer(float32Data.length * 2);
  const dataView = new DataView(pcmBuffer);

  let offset = 0;
  for (let i = 0; i < float32Data.length; i++, offset += 2) {
    let s = Math.max(-1, Math.min(1, float32Data[i]));
    dataView.setInt16(offset, s < 0 ? s * 0x8000 : s * 0x7fff, true);
  }

  // Convert buffer to Base64 and send over WebSocket
  let binary = '';
  const bytes = new Uint8Array(pcmBuffer);
  for (let i = 0; i < bytes.byteLength; i++) binary += String.fromCharCode(bytes[i]);
  ws.send(JSON.stringify({ type: 'audio', data: btoa(binary) }));
};
```

### Step 3: Backend Gemini Live Session
In [`voice-server.js`](file:///c:/Users/25002/Desktop/V0.1/Vedika/vedika/Vyomanta/frontend/voice-server.js):
- Node.js accepts the WebSocket connection at `/api/ws`.
- It rotates API keys (`GEMINI_API_KEY_*`) round-robin to avoid free-tier quota limits.
- Opens a bidirectional session using `ai.live.connect`:
  ```javascript
  const geminiSession = await ai.live.connect({
    model: 'gemini-3.1-flash-live-preview',
    config: {
      responseModalities: [Modality.AUDIO],
      speechConfig: {
        voiceConfig: {
          prebuiltVoiceConfig: { voiceName: 'Zephyr' } // Warm, expressive voice
        }
      },
      systemInstruction: 'Your name is Vedika. You are a warm academic tutor... Keep answers strictly 1-2 short sentences...',
      outputAudioTranscription: {},
      inputAudioTranscription: {},
    },
    callbacks: {
      onmessage: (msg) => {
        // Relays 24kHz audio chunks, transcripts, and interruption signals to browser
      }
    }
  });
  ```
- Audio incoming from client WS is passed directly via:
  ```javascript
  geminiSession.sendRealtimeInput({
    audio: { data: msg.data, mimeType: 'audio/pcm;rate=16000' }
  });
  ```

### Step 4: The Voice & Persona (`Zephyr`)
The voice configuration uses **`Zephyr`**:
- Prebuilt voice provided in Gemini Live API.
- Configured with a system instruction that instructs it to use natural colloquialisms (*"chalo"*, *"got it ya"*, *"no problem at all"*).
- Enforces a **1 to 2 sentence response limit** so that voice delivery sounds immediate, crisp, and human rather than robotic or lecturing.
- Dynamically code-switches between **English, Hindi, Telugu, Hinglish, and Teluglish** based on what the student speaks.

### Step 5: Gapless 24kHz Audio Playback & Barge-In
Gemini responds with raw **24,000 Hz PCM mono audio**:
1. **Gapless Audio Scheduling**: The browser converts Base64 chunks to Float32, creates `AudioBuffer` at `24000 Hz`, and schedules playback consecutively using `nextPlayTimeRef = Math.max(audioCtx.currentTime + 0.05, nextPlayTimeRef) + audioBuffer.duration`. This prevents choppy audio clicks.
2. **Barge-In / Interruption**: When Gemini detects the student speaking while the tutor is talking, Gemini emits `content.interrupted`. The server sends `{ type: 'interrupted' }`, and the browser immediately calls:
   ```javascript
   audioSourcesQueueRef.current.forEach(source => { try { source.stop(); } catch {} });
   audioSourcesQueueRef.current = [];
   nextPlayTimeRef.current = 0;
   ```

### Step 6: Visualizer & Sentiment Feedback
- **3D Robot Visualizer** ([`VoiceRobotVisualizer.jsx`](file:///c:/Users/25002/Desktop/V0.1/Vedika/vedika/Vyomanta/frontend/components/voice-tutor/VoiceRobotVisualizer.jsx)): A Three.js wireframe icosahedron head with an inner glowing sphere that bobs and scales dynamically.
- **Sentiment Analysis**: The backend scans student utterances for keywords across English, Telugu, and Hindi to identify if the student is *Struggling / Confused* (😟), *Happy / Confident* (😊), or *Curious* (🤔), updating the sentiment badge in real time.

## 5. Deployment Architecture

For deployment (e.g., Render Free Tier or cloud containers):
1. **Frontend**: Deployed to Vercel or Node.js host.
2. **Voice Server**: Deployed as a Node Web Service (e.g. on Render) running `node voice-server.js`.
3. Set `NEXT_PUBLIC_VOICE_WS_URL=wss://your-voice-server.onrender.com/api/ws` on the frontend.
4. Render natively proxies `wss://` over port 443 with long-lived WebSocket connections.
